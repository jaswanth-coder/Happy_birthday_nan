# Happy Birthday Nandhini 🎂✨

A personalized, interactive animated birthday greeting website for Nandhini Girija!

## Features
- Interactive step-by-step greeting experience:
  - Ambient glowing lights with sound activation
  - Personalized birthday background music
  - Flying celebration banner & colorful balloons
  - Animated multi-tier cake with candles
  - Custom word balloons spelling: **HAPPY BIRTHDAY NANDHINI GIRIJA**
  - Heartfelt, encouraging message celebrating her special day and cheering her on with PhD research and life goals!

## Preview Locally
Open `index.html` in any modern web browser or start a local static server:
```bash
python3 -m http.server 8080
```
